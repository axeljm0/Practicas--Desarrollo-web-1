Ejercicio 19: El Evento Global Error

Monitoreo y captura centralizada de errores no controlados en tiempo de ejecución mediante el escuchador window.addEventListener("error", ...) y análisis del objeto ErrorEvent.

¿Qué es el evento 'error'?: Es el último mecanismo de defensa de una aplicación web. Cuando un error no es atrapado por ningún bloque try/catch, asciende al objeto global window, permitiendo registrar la telemetría del incidente (archivo, línea, columna y mensaje) antes de que la aplicación colapse.
