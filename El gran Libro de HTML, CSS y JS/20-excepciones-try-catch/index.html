Ejercicio 20: Excepciones con try, catch y throw

Diseño de validaciones defensivas mediante la emisión intencional de excepciones con throw new Error() y su captura controlada con bloques try / catch / finally.

Debe ser un número entero mayor o igual a 18 y menor o igual a 120.
Validado mediante expresión regular estándar (debe contener usuario, '@' y dominio con extensión).
Mínimo 8 caracteres, al menos un número y al menos una letra mayúscula.
