Ejercicio 17: La Consola del Navegador

Identificación y diagnóstico de los 3 errores más frecuentes de programación en JavaScript: función inexistente, acceso a objeto nulo y uso de variable no declarada.

¿Cómo abrir la Consola en tu navegador?
Chrome / Edge: Presiona F12 o Ctrl + Shift + J (Mac: Cmd + Opt + J)
Firefox: Presiona F12 o Ctrl + Shift + K (Mac: Cmd + Opt + K)
Safari: Activa el menú Desarrollo y presiona Cmd + Opt + C
Atajo Universal: Clic derecho en cualquier lugar de la página y elegir "Inspeccionar".
Consola Visual en Pantalla Abre también la consola nativa (F12)
Haz clic en los botones superiores para generar y diagnosticar errores.
Tabla Comparativa: Errores, Causas Comunes y Diagnóstico
Tipo de Error Causa Frecuente Comportamiento en Consola
ReferenceError Se intenta llamar a una función o leer una variable que no ha sido definida en ningún ámbito. Muestra el nombre del identificador faltante y el archivo/línea exacto de la llamada.
TypeError Se intenta acceder a una propiedad o método sobre un valor que es null o undefined. Indica "Cannot read property 'x' of undefined / null" señalando la línea del acceso.
ReferenceError (Modo Estricto) Se asigna o lee una variable sin haberla declarado previamente con var. En modo estricto ("use strict") impide crear variables globales accidentales y arroja error.
